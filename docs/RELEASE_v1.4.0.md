# 1.4.0 · IndexTTS 2.5 台语语言包与音色库

新增“台语（台湾闽南语）”独立语言包，正式模型定位为
`models/extra_language/zh-nan-tw/model/`。恢复 GPT LoRA 与第 100 行台语语言条件，
切回其他语言时禁用适配器。原五种语言继续使用 IndexTTS 2.5 基础模型。

支持普通话自动转台语、台语汉字和带声调台罗三种输入。普通话优先查询来源明确的
整句对译，未命中时使用项目内 Taigi-Llama-2 7B Q4_K_M；译文异步显示并可编辑。
词库由来源材料构建，保留各来源许可、原始文件和 SHA-256。THUOCL 只提供普通话候选。

修复 8 GB 小显存设备参考语音编码器全程驻留 GPU 导致的声学阶段换页问题，改为
参考条件提取时加载，完成或异常后移回 CPU，不改变模型权重和特征精度。
新增 PEFT、本地翻译运行库和简繁匹配依赖，环境标记升级为 1.4.0。

新增项目内音色库：命名保存参考录音副本、下拉切换、重启恢复、确认删除。
原始录音保留，合成期间锁定库操作，异常写入可回滚。

页头简化为“IndexTTS / zeroshot 语音合成”。台语输入方式与翻译档位采用
上标签、下选择框的两列布局；文本卡片正文可滚动，修复普通窗口被强行撑高。
删除台语编辑区的常驻横幅，保留错误与转换状态反馈。

提供三种本地成品：indextts.zip 包含运行环境、2.5 基础模型和台语语言包；
model.zip 为可覆盖解压到程序根目录的台语语言包；release.zip 为无模型、
首次启动安装 even/ 的轻量程序包。详见 DISTRIBUTION.md。

模型与词库不进入 Git 源码或轻量 Release 包。翻译模型仅限非商业用途，各词库许可独立保留。
真实翻译与音频工程检查通过仍不代表所有台语发音和翻译自然度已通过母语者验收。
本文件记录本地改动，GitHub Release 的发布状态以实际远端为准。
