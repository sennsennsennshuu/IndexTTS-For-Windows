# 台语语言包接入设计

用户已指定语言包目录、模型子目录、语言选项和五个词库参考来源。本次采用项目内
独立语言包：`models/extra_language/zh-nan-tw/model/` 保存经过完整性核验的正式
LoRA 与语言行，`words/` 保存对译和读音记录，`translation/` 保存独立本地翻译模型。
历史训练回执保留，迁移另存来源与目标摘要，不覆盖旧验收证据。

桌面程序增加 `ZH-NAN-TW`，显示“台语（台湾闽南语）”。同一基础模型按请求启用
台语适配器；切换回其他语言时禁用 LoRA 并恢复原 tokenizer 与文本前端。训练使用的
minnan ID 100、既有 zh 文本前缀和独立语言行必须一并恢复，不能仅加载 PEFT 权重。

输入方式为普通话、台语汉字、带声调台罗。普通话输入先匹配可信整句对译；未命中时
使用固定修订的本地 Mandarin→Taiwanese 翻译模型，输出带调台罗再合成。辞典辅助
台语词语读音与已确认对译，THUOCL 仅提供中文领域词候选，不将其冒充台语词典。
转换结果在工作线程中生成并可由用户编辑，翻译缺失或失败时不得静默朗读普通话原文。

数据保留来源、原始摘要、许可、台语汉字、台罗、明确普通话对译及歧义候选。抓取不到
或没有可用数据授权的资料源记录限制；不虚构翻译、声调或覆盖率。词库及翻译模型与
语音适配器分别校验，保持正式模型包内文件不被附加说明破坏。

验收包含迁移前后权重摘要、LoRA 开关与中文回切、线程退出及转换编辑、词库构建
真实统计、离线翻译、实际台语音频和原五语言回归。听感与翻译自然度保留人工评审
边界，单纯文件存在或模拟推理不能替代真实合成。
