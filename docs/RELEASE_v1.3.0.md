# v1.3.0 · IndexTTS 2.5 多语种工作台

应用完整切换到官方 IndexTTS 2.5。程序只提供新版引擎，旧版入口、兼容分支与不再使用的模块已移除；需要单独准备 2.5 权重。

## 功能

- 新增中文、英文、日语、西班牙语、阿拉伯语选择。
- 新增 0.5–2.0 时长系数，清晰标注小于 1 更快、大于 1 更慢。
- 支持 `<文字|发音>` 标注，提供拼音、CMU 音素和日语假名示例。
- 保留深色蓝灰工作台、四种情感模式、真实波形、播放定位和高级参数。

## 优化与修复

- 支持的 CUDA 设备采用 BF16；文字情感分类只在需要时加载到 CPU。
- 修复低显存长文本分段拆开英文发音标注的问题，并检查超长原子标注。
- 修复声码器超满幅输出直接写 PCM 导致削波的问题，改用等比例峰值衰减。
- 参考录音在相同路径被覆盖后会刷新条件缓存。
- 合成输出经解码检查后原子提交，失败时清理临时文件并保留已有结果。
- 已有 `even/` 也会根据版本标记补齐新增依赖；安装中断可继续。
- 缺少模型仍能打开工作台，生成前显示缺失文件；推理不会自动访问外部模型缓存。

## 分发与使用

提供 Windows x64 轻量 ZIP，**不包含任何模型或 Python 运行环境**。首次双击 `run.bat` 自动安装项目内 `even/`，依赖下载优先使用清华／阿里云镜像。

模型放置与下载见 `MODEL_SETUP.md`。准备完成后运行 `run.bat --check --with-emotion` 检查环境和模型。

根目录保持 `run.bat`、`start.py`、`requirements.txt` 三个普通文件。具体回归、真实五语言／四情感／时长对比与包校验证据保存在项目验证记录中；不将工程指标等同于母语听审或跨机器性能保证。
